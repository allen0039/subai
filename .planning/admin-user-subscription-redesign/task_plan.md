# 用户、套餐与账号池重构方案编制计划

## 目标

为 SubAI 当前实现编写一份可直接进入开发的详细工作流程方案，覆盖多角色登录、用户自助创建 Key、多套餐选择、账号池分配、上游账号管理、权限隔离、迁移和验收。

## 已确认决策

- 移除“客户端（设备 / Agent）”业务层。
- 管理员和普通用户均可登录，但权限严格隔离。
- 管理员可管理所有用户及密码；普通用户可修改自己的密码。
- 一个用户可同时绑定多个套餐。
- 用户创建 Key 时必须从自己当前可用的套餐中选择一个。
- Key 继承所选套餐的账号池、额度、模型和并发边界。
- 套餐使用内部美元额度，支持日、周、月周期。
- 套餐支持并发上限、允许模型、Key 数量上限和有效期。
- 管理员可向用户追加单个账号或账号池，最终可用范围取并集。
- 账号池支持轮询、权重、优先级故障切换；账号可加入多个池。
- 密码变更后撤销其他登录会话。
