# Sub2API 风格计价改造计划

## 目标

将普通订阅套餐改为 Sub2API 风格的请求后计量：自动维护模型价格目录，按上游真实 usage 分项计算费用，并将套餐倍率后的费用计入用户订阅；保留现有账号池路由、Decimal 金额、价格版本和幂等账本能力。

## 范围决策

- 普通请求不再依赖请求前严格金额预留，响应完成后按真实 usage 计量。
- 价格按不可变版本导入，远程目录更新只影响新请求。
- 套餐版本持有销售倍率；账号池只负责路由容量，不决定用户售价。
- 未知模型或无价格仍然拒绝，不接受静默零价。
- 本轮优先完成文本输入、缓存输入、输出三项的可用闭环，并为更多计费维度保留扩展结构。

## 验收标准

- 新模型进入远程价格目录后可生成并激活新的价格版本。
- 同一请求重试不会重复计费。
- 套餐倍率影响订阅实际消耗，但不改变账号池路由。
- usage 缺失、价格缺失或字段不一致不会记作零费用。
- 日/周/月订阅额度按实际费用累计并阻止后续超额请求。
- `go test ./...`、前端构建和相关 PostgreSQL 集成测试通过。
