## 已知约束

- 目录不在 Git 仓库中；不依赖 Git 回滚。
- 保留旧 `clients` 与 `key_routes` 表/接口的读取兼容，前端不再展示客户端。
- 新 Key 必须绑定一个有效订阅；历史 Key 继续走 `key_routes` 兼容读取，不强制改写既有数据。

## 验收重点

- 普通用户可登录、只能管理本人 Key 和密码。
- 管理员能创建用户、账号池、套餐和多份用户订阅。
- Key 选择一个用户订阅，模型/并发/额度无法越界。
- 请求动态校验订阅状态与路由范围，额外授权不绕过订阅额度。
- Go 测试与前端构建通过。
