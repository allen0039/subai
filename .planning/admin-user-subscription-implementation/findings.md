# 实施发现

- 基线 `go test ./...` 与 `npm --prefix web run build` 均通过。
- 当前项目使用 Go + PostgreSQL + React/Vite；迁移是编号 SQL。
- 成员密码哈希和更新接口已存在，但登录仅允许管理员，且前端未暴露密码编辑。
- 路由当前由 `api_keys` 到 `key_routes` 静态关联；需在不破坏旧 Key 的前提下增加订阅动态解析。
- 预算账本已原子预留/结算；添加订阅作用域和月周期应尽量复用。

## 实施中的设计落点

- 0009 采用纯增加式迁移：新增计划/版本/订阅/授权表，并向既有账号组、Key、请求、账本及预算策略增加列或约束。
- 为避免破坏部署环境，互动会话暂时复用 `admin_sessions` 表，只将鉴权语义扩展到所有活跃成员；后续可另迁移其名称。
- 普通用户资源一律从会话身份派生，不接受 `member_id` 作为用户侧可控路径参数。
- 账号池支持优先级、加权轮询、优先级故障切换三种策略字段；套餐和用户追加授权均以账号池为主要可复用授权单元，用户仍可按需额外绑定单账号。
- 完整 PostgreSQL 集成验证使用临时本地容器，仅用于本次测试，验证完成后移除。
